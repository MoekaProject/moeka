## Features

- Manage multiple workspaces in one FileTree, with draggable root ordering and one active workspace at a time.
- Preserve each workspace's tabs, split panes, unsaved edits and running terminals when switching, and restore workspace layouts on restart.
- Access starred files across workspaces from a shared section above the workspace roots.

## Fixes

- Preserve FileTree selection, expanded directories, filter state and scroll position when switching workspaces. Restore scrolling before row layout to avoid empty frames and position jumps.
- Update Windows taskbar and Alt+Tab titles to follow the focused document, filename and unsaved state.
- Normalize exported images through the editor's RGBA decoding path, including high-bit-depth and floating-point formats such as HDR and OpenEXR. Correct extension handling for encoded image paths.

## Improvements

- Keep inactive workspace roots above or below the current file list, with a separator above the bottom group and independent overflow scrolling.
- Restore Settings and Help buttons beside the localized Add Folder action.
- Build all release packages in GitHub Actions, with isolated macOS signing and notarization, same-run artifact verification, and serial release publication.

## Downloads

- macOS: Developer ID-signed and notarized app bundles in Apple silicon and Intel DMG/ZIP packages.
- Windows and Linux: ARM64 and x86_64 ZIP packages. Windows executables do not currently carry an Authenticode signature.
- HEIC/HEIF/AVIF require the corresponding system image codecs. Windows PDF/PNG export requires WebView2 Runtime; Linux PDF/PNG export requires WebKitGTK.
