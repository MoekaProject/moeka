## Features

- Keep starred files, collapsed state, and sidebar selection independent for each local or SSH workspace. Migrate existing global stars to the active workspace once.

## Fixes

- Restore image tabs when returning to their workspace.
- Finish or cancel pending FileTree creation consistently when switching workspaces or leaving an empty name.
- Expand local and SSH directories after hovering over them while dragging selected resources.
- Use the selected dark theme for an always-dark sidebar after switching to a light theme.
- Open the workspace root menu from empty space below the FileTree, locally and over SSH.
- Preserve open tab and starred-file paths when moving resources between Unix and Windows filesystems.

## Improvements

- Start SSH directory browsing in the remote home directory and provide an add button beside the path input.
- Refine status bar controls, settings menu placement, and sidebar styling.

## Downloads

- macOS: Developer ID-signed and notarized app bundles in Apple silicon and Intel DMG/ZIP packages.
- Windows and Linux: ARM64 and x86_64 ZIP packages. Windows executables do not currently carry an Authenticode signature.
- HEIC/HEIF/AVIF require the corresponding system image codecs. Windows PDF/PNG export requires WebView2 Runtime; Linux PDF/PNG export requires WebKitGTK.

Application source and build scripts: https://github.com/MoekaProject/moeka/tree/v0.1.40
