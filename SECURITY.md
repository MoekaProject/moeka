# Security policy

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/MoekaProject/moeka/security/advisories/new) when enabled. If unavailable, request a private contact in [community issues](https://github.com/MoekaProject/community/issues), sharing only the request for a channel. Keep vulnerability details, reproductions, and sensitive attachments out of public issues and pull requests.

Write the report in English. Include the affected version or commit, platform, distribution channel, impact, minimal reproduction using synthetic data, and any proposed mitigation. Test only authorized systems and redact unrelated private information.

Coordinate disclosure through the private channel. Support timelines and fixes for older versions are assessed per report; no response-time or backport guarantee is offered.
