# MoekaNotes Site

Nuxt + Less static website for the MoekaNotes landing page.

The first implementation is based on the Figma design frame:

https://www.figma.com/design/SOLccdgMhSRTxgDkcolHai/MoekaNotes?node-id=0-1&t=98QJ1hPsAqIXvdhI-1

## Commands

```sh
npm install --registry=https://registry.npmmirror.com
npm run dev
npm run generate
npm run preview
```

The site is isolated under this directory and does not participate in the Rust desktop app build.
